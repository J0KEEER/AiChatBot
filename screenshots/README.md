# Screenshots & Demo Assets

Place your application screenshots, screen recordings, or GIF demonstrations in this folder to display them in the project [README.md](../README.md).

## Recommended File Names

- `gui_demo.png` : Full screenshot of the Swing GUI chat interface.
- `cli_demo.png` : Screenshot or terminal recording of the interactive CLI mode.
- `demo.gif` : (Optional) Short animation of user interaction and live weather/time lookup.

## Linking in README.md

Once added, reference your images directly in the root [README.md](../README.md):
```markdown
![Swing GUI Demo](screenshots/gui_demo.png)
![Interactive CLI Demo](screenshots/cli_demo.png)
```
